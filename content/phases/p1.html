必做

  • system-design-101：前三章（通信协议 / 数据库 / 缓存），每张图对应一个架构决策；把每个模块的"为什么用它"整理成一张表
  • The Twelve-Factor App：通读全部 12 条，每条用一句话写下"违反它的典型后果"，30 分钟内完成
  • awesome-software-architecture：Monolithic / Microservices / Event-Driven Architecture 三个章节，各读 3–5 篇链接

选读

  • Martin Fowler 企业应用架构模式目录：对照 Transaction Script、Domain Model、Table Module 三节，判断你熟悉的业务逻辑属于哪种结构。
  • Revisiting the Outbox Pattern：解释为什么业务更新与 outbox 写入应在同一本地事务完成，以及发布端重试时如何让消费者按事件 ID 去重。
  • 《The Architecture of Open Source Applications》选读：nginx 或 LLVM，找出一个真实的架构取舍。
