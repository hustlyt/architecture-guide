必做

  • system-design-primer：选 URL 缩短（Pastebin）/ Twitter 时间线 / 通知系统 / 聊天系统任意一题，从需求澄清到架构图独立完整完成，不要提前看答案
  • 系统设计面试内幕指南：对照自己的设计看参考答案，逐项找差距，重点关注"你没想到的 edge case 和 scale 问题"
  • 反查 ADR：给你在实战题中做过的 3 个关键决策（数据库选型 / 缓存策略 / 一致性取舍）各写一条 Nygard 格式的 ADR

选读

  • system-design-101：在完成实战题之后，对照图解找出自己设计里遗漏的可靠性 / 可扩展性细节
  • The Architecture of Open Source Applications：选一个与你实战题相关的项目（如 Nginx 对应 API Gateway 题），看真实系统如何权衡
  • awesome-system-design-resources：挑一个垂直领域（搜索 / 推荐 / 支付 / 存储）深读专题资料，把毕业项目做到这个深度
