P2 · 第 4 周

DDD 与领域建模

Bounded Context、聚合根、CQRS、防腐层，从贫血模型到充血模型的演进

要读什么

必做

  • 《软件设计的哲学》中文版：前 8 章（复杂度 / 深模块 / 信息隐藏 / 通用接口 / 注释），建立"模块边界怎么划"的语言
  • modular-monolith-with-ddd：读 README 和项目结构目录树，理解 Bounded Context 在代码里如何体现；不用读全部 C# 代码
  • DDD 在大众点评交易系统演进中的应用：美团一线实践，重点看从贫血模型到 DDD 的演进和防腐层的落地方式。

选读

  • awesome-software-architecture DDD / CQRS / Event Sourcing 章节：补全 DDD 战术设计词汇（Entity / Value Object / Aggregate / Domain Event）
  • 凤凰架构 微服务章节 3–4：微服务拆分粒度与 DDD Bounded Context 的对应关系
  • Outbox Pattern 复习：DDD 里聚合根事务和领域事件发布的衔接点
✔ 学完应做出：给一个真实业务（电商下单/用户中心/内容发布任选其一）划定 Bounded Context，定义核心聚合根和领域事件。
