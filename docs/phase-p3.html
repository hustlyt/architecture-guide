P3 · 第 5–6 周

分布式系统原理

DDIA 核心章节：复制、分片、事务、网络与节点故障、一致性与共识

要读什么

必做

  • DDIA 逐章精读第一版第 5–9 章，或 DDIA 第二版第 6–10 章。按复制、分片、事务、分布式系统的故障、一致性与共识阅读。分别解释事务隔离的可串行化和读写语义中的线性一致性。
  • 凤凰架构 分布式事务章节：TCC / Saga / 本地消息表 / 事务消息，每种模式的代码示例和工作原理
  • Gilbert 与 Lynch 的 CAP 回顾：给订单查询和库存扣减分别画出网络分区时的行为，标明响应条件、读写保证和恢复策略。

选读

  • 系统日知录：分布式系统经典论文精读（Raft / Paxos / Spanner / DynamoDB），深挖一致性算法的理论基础
  • 云原生架构笔记：Kubernetes / 服务网格 / 可观测性，从工程实现看 DDIA 抽象概念如何落地
  • 凤凰架构 · Gossip 协议：对照同节的 Paxos、Raft，区分消息传播与对同一决策达成共识。
✔ 学完应做出：读完 DDIA 的分布式数据部分。挑一个业务操作，说明网络分区时哪些读写可继续、哪些要拒绝或延迟，以及恢复后怎样处理冲突。
